# Licensing and reuse

Original software uses MIT; original reports, documentation prose, charts, layouts and prompt/skill text use CC BY 4.0. Both permit commercial reuse and adaptation. These grants cover only rights held by the project.

| Material | Terms |
|---|---|
| Original code, scripts, tests, configuration, deployment files and code examples | MIT; retain the copyright and permission notice in LICENSE. |
| Original editorial content and charts | CC BY 4.0, to the extent copyright or similar rights exist and are held by tbitcs; see LICENSES/CC-BY-4.0.txt. Attribute, link the license and source, and identify changes. |
| Original selection/arrangement of released aggregate evidence | CC BY 4.0 only for compilation/database rights held by the project. Individual records retain provider terms. Public-domain facts acquire no new restrictions. |
| External data, graphics, logos, publications and quotations | Provider terms in THIRD_PARTY_NOTICES.md; no blanket relicensing under MIT or the project's CC grant. |
| Spec Kit scaffolding, scripts, templates and derived agent instructions | Upstream MIT, Copyright GitHub, Inc.; preserved in LICENSES/Spec-Kit-MIT.txt. This includes upstream prose within .specify and Spec Kit skills. |
| Dependencies and runtime components | Their respective licenses and notices. |
| Confidential employer records, credentials and private database volumes | Excluded from these grants and public release packages. |

Suggested report attribution: “Michigan Workforce Intelligence, maintained by tbitcs, report title and release version, https://github.com/AXIOVEX/michigan-workforce-intelligence, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).” Describe adaptations and retain applicable provider credits. This example adds no extra license conditions.

O*NET OnLine content is separately CC BY 4.0. Preserve its attribution, change and non-endorsement notices; authorized graphics and trademarks retain their conditions. Government sites may contain third-party material, and state publications must not be presumed public domain. API rules and redistribution conditions remain applicable; see [source policy](docs/source-policy.md) and [third-party notices](THIRD_PARTY_NOTICES.md).

MIT supports straightforward software reuse without requiring derivative software to be open source. CC BY 4.0 supports attribution for reports without noncommercial or no-derivatives restrictions that obstruct employer reuse. Creative Commons [recommends software-specific licenses for software](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software).

Public download/fork/reuse rights do not grant repository push access, which remains separately restricted to the maintainer through GitHub. Neither grant implies agency or candidate-institution endorsement or grants access to private information. No warranties are provided; consult the full license texts. Where package copies flatten the LICENSES directory, the same license texts appear at the archive root.
