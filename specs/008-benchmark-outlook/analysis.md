# Analysis

All requirements are mapped to tasks. Official unemployment definitions and sampling limitations are analyzed rather than presuming fabrication. Hidden hardship has overlapping populations and cannot be summed into an invented true unemployment count. Forecasts remain derived model estimates with source IDs and validation, not new observed evidence. Release replacement is explicitly authorized; old release deletion waits until the replacement is concrete and reviewed.

FR-006 maps to T006: official candidate catalog, MCP labels and report matrix. FR-007 maps to T007: public settings, all-branch ruleset, anonymous asset verification. User authorization supersedes the bootstrap private-only setting. RTK is unavailable on the host; native commands are used, with strict RTK container CI retained.
