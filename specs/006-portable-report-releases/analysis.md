# Analysis and checklist

- Distinguish 2025 closure proposals from current admissions pages; dated center status is not a real-time seat guarantee.
- Keep youth, incumbent, student and inbound denominators separate; avoid duplicate public reimbursement.
- Read-only reanalysis must fail on bad ledger, artifact hashes or missing database; no silent empty initialization.
- Native launcher uses argument lists and pathlib; no Bash/PowerShell dependency, shell interpolation or host PDF packages.
- Release builds use only tracked reviewed sources/snapshot, fixed version validation, immutable tags, pinned actions and allowlisted archive contents.
- Validate actual PDF pages visually and mechanically; test bad versions, failed subprocesses, missing inputs, protected data handling and portable paths.
- Local application CI is required before commit; cloud release/portable validation is explicitly authorized by the user.
